# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People learning Uxntal and developers building and running Uxn/Varvara programs.

## Product Purpose

An all-in-one, browser-based Uxn programming workbench, deployed at https://robertbrook.github.io/ux/.

## Capabilities and Constraints

The confirmed scope is a Uxntal editor and assembler, WebAssembly Uxn runtime, ROM import/export, Varvara screen/audio/input/files, debugger, examples, and reference. Projects are saved locally in the browser. The static application must run on GitHub Pages without a server.

## Product Principles

- Make edit, assemble, run, and inspect a single connected workflow.
- Execute real programs, not simulated previews.
- Keep source and files under the user's control.
- Explain compatibility limitations explicitly.
